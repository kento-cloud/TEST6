# サムネイル デザイン定義 / ナレッジ

> 現行サムネイル（横型=動画サムネ 13枚 / 縦型=番組サムネ 10枚）を1枚ずつ精査し、
> 制作者ごと・テンプレートごとのデザインの「型」をナレッジ化したもの。
> AI生成（gpt-image-1）やデザイナー外注で再現・量産する際の指針として使う。
>
> 注記: 現状の画像は PIVOT のビジネス系ストック素材を流用したデモ。
> 文言（AI MEDIA のタイトル）と絵が一致していないケースがあるが、
> **本書はあくまで「絵そのもののデザイン仕様」を定義する**。

---

## 0. 共通仕様（キャンバス）

| 種別 | 用途 | 解像度 | 比率 | フォーマット | 配置 |
|---|---|---|---|---|---|
| 横型 OGP | 動画カード / 詳細 / OGP | 1029 × 540 | 約 16:9 | WebP (VP8) | `public/images/static/converted/chapter/{id}/ogp/{id}.webp` |
| 縦型 | 番組（プログラム）サムネ | 848 × 1200 | 約 2:3 | PNG | `public/images/programs/thumbnail_vertical/{hash}.png` |

- セーフエリア: 横型はカード上で角丸＋ホバーで縁取り（`ring`）がかかるため、**端から約24px は装飾を置かない**。
- 横型は一覧で最小幅 ~300px まで縮むため、**主見出しは最大2行・最短語数**で可読性を確保する。

## 1. 横型（動画サムネ）— テンプレート分類

13枚は大きく **5系統** に分かれる。各系統は「制作者の型」として扱う。

### A. PIVOT TALK 対談テンプレート（最頻出・基幹フォーマット）
対象: `14365` `14287` `14305` `14364` `14357` `12600` `14363`

```
┌───────────────────────────────────────┐
│  [見出し 2〜3行 / 白 or 黒・極太ゴシック]      │  ← 上 or 中央寄せ
│                                         │
│                          (背景: 実写)     │
│  ┌──────────────┐                        │
│  │ PIVOT TALK   │   ● ● ● ●  or 大きめ人物  │  ← 左下ロックアップ＋人物
│  │ BUSINESS     │                        │
│  └──────────────┘                        │
└───────────────────────────────────────┘
```

**デザイン定義:**
- **構図**: 左下に「PIVOT TALK + ジャンル」ロックアップを固定配置。人物は切り抜き（円形小カット複数 or 大きめ半身1〜2名）。背景はテーマを象徴する実写（球場・都市・軍事・ステージ・夜景）。
- **カラー**: 背景実写に依存。見出しは白（暗背景）/ 黒（明背景）を地色で出し分け。ジャンル名に**ブランドアクセント（シアン〜ブルー グラデ）**の帯。
- **タイポ**: 見出し=極太ゴシック（角ゴ/Bold〜Heavy）。1行に強調語、改行で区切る。`#2` のような話数を小さく添える。
- **人物処理**: 背景から切り抜き、軽いドロップシャドウ。複数人は等間隔の円形 or 並列バスト。
- **用途**: 対談・インタビュー番組のレギュラー回。シリーズ感・信頼感重視。

個別メモ:
- `14365` 球場×投手のダイナミック実写＋下部に4名円形カット。BASEBALL。
- `14305` 単独スーツ人物＋軍事背景。黄色の話数`#2`＋白見出し。ニュース寄りの硬質トーン。
- `14357` 単独人物＋マーライオン/シンガポール背景。横長の白見出しを上部に。
- `14364` `14363` 暗いステージ/ライブ背景＋2名。白見出し＋ブルー差し色。
- `12600` ピンク系明背景＋2名。**下半分に特大見出し**（地色が明るいので黒文字）。
- `14287` SCIENCE。宇宙/人体ビジュアル＋人物。シアン差し色。

### B. ナンバー型インタビュー「N questions」テンプレート
対象: `14328`

```
┌───────────────────────────────────────┐
│  ┌────┐                                 │
│  │ 9  │ questions      [副見出し小]       │
│  └────┘                  ┌──────────┐    │
│   ↑特大数字              │ 右に縦組み   │    │
│   (人物2名)              │ 強調見出し   │    │
│                          └──────────┘    │
└───────────────────────────────────────┘
```

**デザイン定義:**
- **構図**: 左に「特大の数字＋questions」を主役化。右に黄/白の強調見出しを縦積み。人物は中央〜左に配置。
- **カラー**: ダークオリーブ/ニュートラル地＋白文字、強調語に黄。
- **タイポ**: 数字が圧倒的に大きい（画面高の~60%）。`questions`は細め。見出しは太ゴシック。
- **用途**: 「○つの問い」式の構成が決まった単独人物インタビュー。

### C. マネー/エンタメ・ハイテンション テンプレート
対象: `14325`

```
┌───────────────────────────────────────┐
│ ▌借金1000万円 ↑  [赤×白・縁取り極太]       │
│ ▌資産2.5億円    😲😆😲  ← 大袈裟な表情     │
│  MONEY SKILL SET  [出演者名 #1]           │
└───────────────────────────────────────┘
```

**デザイン定義:**
- **構図**: 上段に数字インパクトの見出しを2段。複数の驚き顔カットを下〜右に賑やかに。
- **カラー**: 高彩度（赤・黄・白）。見出しは白文字＋**太い黒/赤フチ**で実写の上でも視認性確保。
- **タイポ**: 極太、矢印（↑↓）や記号で増減を可視化。数字は最大級。
- **用途**: 金融・副業・ビフォーアフター。クリック誘引（YouTube的）。賑やかさ＝期待値。

### D. ランキング/比較テンプレート
対象: `14317`

**デザイン定義:**
- 左上に小さな**ジャンルバッジ**（例「ランキング超分析」赤背景の角丸）。
- 見出しはキーワードに**色分け**（例「生成AI」緑／「Gemini」白）。
- 人物は横一列の等間隔バスト（4名）。比較・序列を示す均等配置が肝。
- 末尾に対象名＋話数（`Gemini #2`）。

### E.「虎の巻」シリーズ・サブブランド テンプレート
対象: `14316` `14293`

**デザイン定義:**
- 左下に**「ビジネス 虎の巻」ロゴ**（白ゴシック＋黄背景×黒の筆書き風斜体「虎の巻」）を固定。
- 見出しは2行・白（必要に応じ赤強調）。人物は2〜3名のバスト。
- 背景は緑系のフラットorグラデ。**サブブランドのロゴ統一**でシリーズ識別。

## 2. 縦型（番組サムネ）— テンプレート分類

10枚は **3系統** に分かれる。

### P1. PIVOT ロゴ主役・3Dミニマル テンプレート
対象: `68a44eea919df`(BUSINESS/紫桃) `68b10dc8e26ae`(MONEY/金) `6992ae87d58d4`(NEWS/紫)

```
┌──────────┐
│ PIVOT TALK│  ← ロゴ＋ジャンル（上1/3）
│ BUSINESS  │
│           │
│  ((  ))   │  ← 3Dオブジェ（ミラー配置のマイク）
│  ||  ||   │     or 下部に人物1名
└──────────┘
```

**デザイン定義:**
- **構図**: 上1/3に「PIVOT + ジャンル」ロックアップ。下2/3に**単色トーンの3Dマイク（左右ミラー）**、または人物1名を配置。
- **カラー**: ジャンル別の**モノクロマティック配色**で識別。
  - BUSINESS = 紫→ピンク グラデ
  - MONEY = ゴールド/タン 単色
  - NEWS = 紫グラデ（下に人物）
- **タイポ**: `PIVOT` 極太＋`TALK/NEWS` 細字の2ウェイト。ジャンル名は特大アウトライン気味。
- **トーン**: 余白多め・上質・静か。レギュラー番組の「顔」。
- **用途**: 番組の親ブランド。色だけ変えてシリーズ展開（テンプレ資産化に最適）。

### P2. SKILL SET 系・コンセプトグラフィック テンプレート
対象: `68a44f67ce787`(BODY/二重露光) `68a44fe6cf874`(MONEY EXTRA/ポップ) `6992ae66c1a19`(MONEY/オレンジ抽象)

**デザイン定義:**
- **構図**: 中央〜上に「◯◯ SKILL SET」の2〜3段見出し。下に人物 or コンセプト画像。
- **バリエーション（同ブランド内で表現が分岐）**:
  - **BODY**: ネイビー地＋シアン。横顔シルエットに骨格/X線を**二重露光**で合成。知的・クール。
  - **MONEY EXTRA**: ネイビー地＋オレンジ/ブルーの**幾何ポップ図形（○×線）**を散らす。人物カット。明るく軽快。
  - **MONEY**: オレンジの**抽象テクスチャ（手描き円・かすれ）**＋笑顔2名。温かくフレンドリー。
- **タイポ**: 太ゴシック。`SKILL SET` を共通キーワードに、頭の単語でジャンル切替。`MONEY` の `Y` を `¥` に置換する遊びあり。
- **用途**: 教養・スキル系。**同ブランドでもトーンを変えて回ごとの空気を出す**自由度の高い枠。

### P3.「新常識 / 虎の巻 / ECONOMICS」バラエティ・ポップ テンプレート
対象: `6992ae170452c`(健康 新常識) `6992ae2d5aaee`(教育 新常識) `6992adf73eb7a`(ECONOMICS) `68fecee954a36`(ビジネス 虎の巻)

```
┌──────────┐
│  [ジャンル白]│  ← 上: 白ゴシック
│ ▟新常識▙  │  ← 中: 赤/黄ボックス＋太字（斜め）
│  😮  😆   │  ← 下: リアクション2名
└──────────┘
```

**デザイン定義:**
- **構図**: 上=ジャンル名（白）、中=**色ボックスに囲った主題（斜め配置で躍動）**、下=表情豊かな出演者2名のバスト。
- **カラー**: 原色ベタ＋同心円/コンフェッティで賑やかさ。
  - 健康 新常識 = ブルー地＋赤ボックス
  - 教育 新常識 = イエロー地＋赤ボックス＋カラフル図形
  - ECONOMICS = ライムグリーン地＋ブルーの角丸ブラケット枠 `1[ECONOMICS]1`
  - 虎の巻 = グリーン同心円＋黄ボックス＋黒の筆書き風斜体
- **タイポ**: 極太ゴシック中心、斜体・縁取り・ボックス囲みで強弱。**サブタイトルは必ず色ボックスで隔離**。
- **トーン**: 親しみ・わかりやすさ。リアクション顔でエンタメ性。
- **用途**: 教養バラエティ・入門枠。番組ジャンルを色で即判別させる。

## 3. デザイントークン（再現用まとめ）

### レイアウトの黄金則（横型）
1. **ロゴ/ブランドは左下固定**（PIVOT TALK ロックアップ or サブブランドロゴ）。
2. **見出しは2行以内・キーワード強調**（色分け or フチ）。話数 `#N` は小さく添える。
3. **人物は切り抜き＋影**。複数人は等間隔、単独は片側＋背景実写。
4. **背景はテーマの実写 or ブランドカラーのフラット**。情報量は見出しと競合させない。

### レイアウトの黄金則（縦型）
1. **上1/3〜1/2にタイトル**、下に人物 or コンセプト画像。
2. **ジャンルは色で識別**（同テンプレを色替えで量産）。
3. **サブタイトルは色ボックスで隔離**して視認性を担保。

### カラーパレット（観測値・参考）
| 用途 | 値（近似） |
|---|---|
| BUSINESS（紫→桃） | `#7C3AED` → `#EC4899` |
| MONEY（金） | `#C8A24B` 系モノトーン |
| NEWS（紫） | `#6D28D9` → `#A78BFA` |
| 新常識ブルー | `#1E66C8` 系 ＋ 赤 `#E23B3B` |
| 教育イエロー | `#F2C200` 系 |
| ECONOMICS ライム | `#B6E000` ＋ ブルー `#1B2C8A` |
| 虎の巻グリーン | `#2DBE3C` 系 ＋ 黄 `#F2E800` |
| マネー・ハイテンション | 赤 `#E11D2A`／黄 `#FFD400`／白フチ |

> ⚠️ 当サイトのフロントは緑テーマ（`#16a34a` 系）。
> 既存サムネは PIVOT 由来の多色配色のままで、サイトのブランドカラーとは未統一。
> 新規サムネを起こす場合は、**P1（ロゴ主役・色替え）テンプレを緑系トークンで再構築**するのが
> サイト全体の統一感の面で最も効果的。

### タイポグラフィ指針
- 和文: 極太角ゴシック（Heavy / Black）。見出しは詰め気味、サブは色ボックス内。
- 欧文ブランド: `PIVOT`(極太) + サブワード(細字) の2ウェイト・ロックアップ。
- 数字インパクト: 金額・話数・順位は**最大級サイズ＋記号（↑↓ ¥ #）**で可視化。

## 3.5 実装：管理画面のデザインテンプレート・モジュール

本ナレッジの横型 A〜E は、管理画面のサムネ生成にモジュールとして実装済み。

- 定義: `src/lib/ai/thumbnail-templates.ts`
  - 各テンプレ = メタ情報（name / palette / diagram / slots）＋ `buildPrompt(slots)`。
  - `buildPrompt` が本書のデザイン定義（構図・配色・タイポ・人物処理）を構造化プロンプト化し、
    画像生成モデル **gpt-image-2（= image 2.0）** に渡す。日本語見出しは「正確に描く」指示付き。
- 配信API: `GET /api/thumbnail-templates`（UI用メタ情報。buildPromptは非公開）。
- 生成API: `POST /api/videos/{id}/thumbnails/generate` に `templateId` ＋ `slots` を渡すと
  サーバー側でプロンプトを構築して生成。`thumbnails.style_preset` にテンプレIDを記録。
- UI: `src/components/ThumbnailGenerator.tsx`（管理画面 動画編集ページ）
  - 「デザインテンプレート」タブで A〜E をカード選択 → 見出し・配色・話数などのスロットを入力 → 生成。
  - 「カスタム / プリセット」タブは従来の自由入力・DBプリセット方式。

> 新テンプレを足す場合は `THUMBNAIL_TEMPLATES` に1エントリ追加するだけで
> API・UI・生成すべてに自動反映される（縦型 P1〜P3 もこの形式で追加可能）。
